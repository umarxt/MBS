# 💍 معرض صور الزواج

منصة صور أنيقة وفخمة لعرض صور المناسبة على كل من حضر — بتصميم عصري، خط **IBM Plex Sans Arabic**،
وهوية لونية راقية. الصور تُجلب مباشرة من **مجلد Google Drive**، ولكل صورة زر **تحميل بأعلى جودة**.

<div dir="rtl">

## ✨ المزايا

- 🎞️ **معرض Masonry** بتوزيع «أقصر عمود» مثل بينتريست — الصور الطولية تتوزّع بأناقة بين العرضية.
- 🧱 **ثبات تام بلا قفز**: يُحجز إطار كل صورة مسبقاً (نسبة الطول/العرض) فلا تتحرك الصور أثناء التحميل.
- ⚡ **فتح/تحديث فوري**: يُخزّن المعرض في المتصفح ويظهر مباشرة عند الرجوع أو التحديث، ثم يراجع الخادم بصمت.
- 🖼️ **عارض صور (Lightbox)** بملء الشاشة: تنقّل بالأسهم / السحب على الجوال / لوحة المفاتيح.
- ⬇️ **تحميل يحفظ في معرض الجوال**: زر على كل صورة وفي العارض — على iOS/Android يحفظ الصورة مباشرة في «الصور/المعرض» عبر Web Share، وعلى الحاسوب يُنزّلها كملف بأعلى جودة.
- 📁 **مصدر واحد**: أضف صورة للمجلد → تظهر بالموقع تلقائياً (لا تعديل كود).
- 🎨 الهوية اللونية: كحلي فاخر · ذهبي · نعناعي · أوف‑وايت.
- 🌐 عربي بالكامل (RTL) وسريع الفتح على الجوال.

## 🚀 التشغيل — 3 خطوات فقط

### 1) انشر سكربت جلب الصور (Google Apps Script)
افتح ملف [`apps-script.gs`](./apps-script.gs) واتبع التعليمات المكتوبة في أعلاه:
1. https://script.google.com ← **New project** والصق محتوى الملف.
2. ضع مُعرّف مجلد الدرايف في `FOLDER_ID`.
   - المُعرّف = الجزء بعد `folders/` في رابط المجلد:
     `https://drive.google.com/drive/folders/`**`XXXXXXXX`**
3. اجعل المجلد **عاماً**: مشاركة ← «أي شخص لديه الرابط» ← **مُشاهِد**.
4. **Deploy ← New deployment ← Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخ رابط الـ **Web App** (ينتهي بـ `/exec`).

### 2) اربط الرابط بالموقع
افتح [`config.js`](./config.js) والصق الرابط في `WEB_APP_URL`،
وعدّل اسم العروسين والتاريخ والجملة الترحيبية:
```js
window.GALLERY_CONFIG = {
  WEB_APP_URL: "https://script.google.com/macros/s/AKfyc.../exec",
  eyebrow:     "بمناسبة زواج",
  coupleNames: "أحمد & نورة",
  eventDate:   "١٤٤٧ هـ",
  subtitle:    "شكراً لحضوركم ...",
};
```

### 3) شغّل / انشر
- **محلياً للتجربة:** من مجلد المشروع
  ```bash
  python3 -m http.server 8080
  # افتح: http://localhost:8080
  ```
  (أي خادم ثابت يعمل — لا يوجد Build.)

- **النشر المجاني (GitHub Pages):**
  المستودع ← **Settings ← Pages** ← Source: فرع `main` (المجلد الجذر) ← Save.
  خلال دقائق يصير للموقع رابط عام يُفتح على أي جهاز.

  > بدائل بنفس السهولة: **Cloudflare Pages** أو **Netlify** — اسحب المجلد أو اربط المستودع، بدون أمر بناء.

## ❓ أسئلة سريعة

- **الصور لا تظهر؟** تأكد أن المجلد والصور «أي شخص لديه الرابط»، وأن النشر بصلاحية **Anyone**.
- **أضفت صوراً ولم تظهر فوراً؟** هناك تخزين مؤقت 5 دقائق — أعد النشر أو افتح رابط الـ Web App مضيفاً `?nocache=1`.
- **جودة التحميل؟** زر التحميل يجلب **الملف الأصلي** من الدرايف بأعلى جودة كما رُفع.
- **كيف تُحفظ الصورة في معرض الجوال؟** على iOS/Android يفتح الزر خيار المشاركة → اختر **«حفظ الصورة»** فتُحفظ في «الصور/المعرض» مباشرة. (على iOS إن ظهرت الصورة بدل خيار الحفظ: اضغط عليها مطوّلاً ثم «حفظ الصورة».)
- **الصور تقفز أو تتأخر عند التحديث؟** لم يعد يحدث: يُحجز إطار كل صورة مسبقاً ويُعرض المعرض من كاش المتصفح فوراً. لتخطيط فوري بلا قياس، يمكنك (اختياري) تفعيل **Drive API** في محرر Apps Script — التفاصيل أعلى ملف `apps-script.gs`.
